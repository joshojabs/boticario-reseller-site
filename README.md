# O Boticário Independent Reseller Catalogue — V5

## What changed
- Portuguese is now the default language everywhere.
- The language button opens as `🇵🇹 PT` and is forced to remain visible across phone, tablet and desktop layouts.
- Pressing the button switches the whole interface to English (`🇬🇧 EN`) and pressing it again returns to Portuguese.
- All exact prices and promotional prices have been removed.
- Exact price fields were also removed from the product dataset itself, so there is nothing stale to maintain later.
- Product pages and WhatsApp messages now focus on availability and current offers instead.
- Search, filters, favourites and direct product WhatsApp enquiries are unchanged.

Temporary WhatsApp test number remains in one place in `script.js`.
